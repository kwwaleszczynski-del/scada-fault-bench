scada-fault-bench

An open benchmark for fault detection in wind and PV SCADA data. Faults with a known time, device and size are injected into clean stretches of open datasets; every method is scored by the same evaluation, with block-bootstrap confidence intervals. Code and README.

The injected faults are a signal-level model, not recorded failures, and the intervals only describe the sampling inside this benchmark. A result here does not show that a method is better in general. See the limitations in the README.

Results

Values with 95 % intervals (block bootstrap over four-week blocks of the test blocks). F1, recall and precision are per event and alarm; the delay is the mean over detected events; the false alarm rate is in hours per year of healthy time (a calibrated method aims at the same budget). Excess recall is recall minus chance recall (what the same alarms hit on the untouched test block); methods with a scope are scored only on the fault types in their channels. Click a header to sort. n/a: no event, no alarm, or fewer than five detected events for a delay.

Sensitivity to the size of the fault

Excess recall of each of the five sizes: the share of injected events that were detected minus the share that the same alarms hit on the untouched test block (selection of profile and dataset above; only fault types a method is scored on). Zero is chance. Bars: 95 % interval.

Excess recall by fault type

Excess over chance, selection of profile and dataset above; a dash is a fault type the method is not scored on; red is below chance.

Excess recall against false alarms

One point per method for the selection above; bars: 95 % intervals. Calibrated methods share an operating point on healthy calibration data, rule-based ones do not.
